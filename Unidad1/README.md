# Unidad 1

Prácticas de la Unidad 1 de la asignatura **Simulación** (Universidad Nacional de Loja).

| Carpeta | Contenido |
|---|---|
| [`APE4/`](APE4/) | Simulación SIR en Java sin bibliotecas externas, con modelos NetLogo para comparar resultados. |
| [`practica1/`](practica1/) | Probabilidad de lluvia hora por hora a partir de humedad, nubosidad y temperatura; compara un modelo de predicción inicial con uno ajustado. |
| [`practica2/`](practica2/) | Comparación de modelos determinísticos, estocásticos, discretos y continuos aplicados al crecimiento poblacional. |
| [`practica3/`](practica3/) | Simulación de un sistema de colas M/M/1 con SimPy y comparación de los resultados simulados con los valores teóricos. |
